About File Cleaner

File Cleaner is a small, install-free web app for people who want to clean image metadata and prepare files before sharing them publicly.

Why it exists

Images can carry hidden data such as camera details, GPS location, timestamps, editor information, AI generation tags, C2PA metadata, and Stable Diffusion PNG parameters. File Cleaner gives creators a quick way to make cleaner copies in the browser.

Free to use

Files are processed on your device. Our server manages sign-in and guest usage limits without receiving your files. Guests get 3 files per day; a free account gives you unlimited daily use.

Current focus

The current version focuses on JPEG and PNG image cleanup plus bulk renaming. Other formats can be renamed; their metadata is unchanged. Read more about the tool’s limitations.

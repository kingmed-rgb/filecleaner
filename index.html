Questions people ask before using it.

Are my files uploaded?

No. This is a static browser app. Files are read locally by your browser and saved back as downloads.

Does it remove EXIF and GPS metadata?

Yes. JPEG and PNG files can be redrawn as fresh images, which removes embedded EXIF camera data, GPS location tags, timestamps, and many file-level metadata fields.

Does it remove AI tags and C2PA metadata?

For supported images, canvas export can remove file-level AI metadata, C2PA Content Credentials metadata, and PNG text chunks. It cannot remove invisible watermarks or anything baked into the pixels.

Does it remove Stable Diffusion prompts?

Stable Diffusion prompts and workflow data are often stored in PNG text chunks. Redrawing the PNG and exporting a new file helps remove those embedded chunks.

Does it remove metadata from every file type?

No. JPEG and PNG files can be cleaned by redrawing them. PDF, DOCX, ZIP, video, audio, and other file types are currently renamed only.

Will image quality change?

Cleaned images are exported as new JPEG or PNG files. PNG keeps lossless output, while JPEG is re-encoded at high quality.

Why do multiple download prompts appear?

Each processed file is saved individually by the browser, so larger batches may trigger several download confirmations.

Can I use it on mobile?

Yes. File picking works on mobile browsers, and clipboard image support depends on the browser.
